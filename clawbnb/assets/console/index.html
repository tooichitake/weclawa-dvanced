计费 (Stripe)

      

        Stripe webhook 接 POST /api/v1/billing/stripe-webhook（HMAC-SHA256 验签）。事件实时改 tenants.billing_status:
        invoice.paid → active；invoice.payment_failed → pending (grace 7d)；
        customer.subscription.deleted → suspended。
      

      
Webhook 配置

      
endpoint: https://<your-daemon>/api/v1/billing/stripe-webhook
secret env: WECLAWBOT_STRIPE_WEBHOOK_SECRET (whsec_...)
signing algorithm: HMAC-SHA256 (Stripe-Signature header)
replay window: 5 min

SSO (OIDC + SAML)

      

        企业版 (--features ee) 支持 OIDC (Okta/Azure AD/Google) 和 SAML 2.0 (Okta/AD FS) 接管员工登录。
        每 tenant 一份 IdP 配置；首次 SSO 登录自动 JIT-mint read_only admin key，super_admin 后续可升级 role。
      

      
OIDC 配置（per-tenant）

      

        
Issuerhttps://<idp> (e.g. https://accounts.google.com)

        
client_id来自 IdP application page

        
client_secret来自 IdP application page (sensitive)

        
redirect_urihttps://<daemon>/api/v1/auth/sso/oidc/callback

        
scopesopenid email profile (default)

        
jwks_uri来自 IdP .well-known/openid-configuration

      

      
SAML 配置（per-tenant）

      

        
sp_entity_idhttps://<daemon>/api/v1/auth/sso/saml/metadata

        
idp_entity_id来自 IdP metadata XML

        
idp_sso_urlHTTP-Redirect binding endpoint

        
sp_acs_urlhttps://<daemon>/api/v1/auth/sso/saml/acs

        
idp_x509_cert_pem用于 verify SAMLResponse signature (v5.1 实施)

      

      

        配置入口：当前通过 tenants 表 SQL UPDATE
